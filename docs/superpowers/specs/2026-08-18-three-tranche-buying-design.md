# 交易管理系统 V5：固定三批买入设计规格

## 1. 背景与目标

当前工作簿以“一笔交易只有一次买入”为计算口径，不能表达同一只股票分批建仓。V5 在不新增工作表、不使用宏的前提下，让每笔交易最多记录三批买入，并继续采用一次性全部卖出。

目标：

- 日常操作仍集中在“单次交易”工作表。
- 第二批、第三批按需填写，不增加额外流水表。
- 所有风险、盈亏、锁仓和动态止损计算统一使用累计股数与真实加权买入成本。
- 加仓前若会突破单笔或账户风险上限，Excel 必须给出强制拦截；即使通过粘贴绕过数据验证，“分仓规则检查”也必须显示违规。
- 保留已有 100 笔历史交易，其原买入记录视为第一批买入。

## 2. 范围与非目标

本次包含固定三批买入、累计成本与风险计算、相关公式和验证规则的联动修改。

本次不包含：

- 第四批及更多批次；
- 分批卖出；
- 自动获取行情或每日自动提醒；
- VBA、Office Script 或其他宏；
- 改变既有锁仓、动态止损及交易预期规则本身。

## 3. 用户操作流程

1. 首次建仓时，沿用原位置填写交易信息、第一批买入价、第一批买入股数、首次买入日期、初始止损和交易预期。
2. 需要加仓时，在同一行填写第二批买入价与第二批买入股数；再次加仓时填写第三批对应字段。
3. 每批价格和股数必须成对填写，股数必须为 100 的整数倍；第三批只能在第二批已完整填写后录入。
4. 每次填写或修改加仓数据后，查看“分仓规则检查”。只有显示“通过”时，该笔分仓才符合规则。
5. 最终卖出仍在“持仓跟踪”填写真实卖出价；系统同步累计买入股数并按全部卖出计算最终盈亏。

## 4. 数据结构

“单次交易”中复用并明确以下原有字段含义：

- E：第一批买入价（原“买入价”）
- H：第一批买入股数（原“买入股数”）
- I：首次买入日期（原“买入日期”）
- O：买入总费用（原“买入费用”）

在 V4 的 AJ 列之后新增 AK:AR：

| 列 | 字段 | 输入/计算 |
|---|---|---|
| AK | 第二批买入价 | 人工输入，可空 |
| AL | 第二批买入股数 | 人工输入，可空 |
| AM | 第三批买入价 | 人工输入，可空 |
| AN | 第三批买入股数 | 人工输入，可空 |
| AO | 实际加权买入价 | 公式 |
| AP | 累计买入股数 | 公式 |
| AQ | 当前持仓风险 | 公式 |
| AR | 分仓规则检查 | 公式 |

“单次交易”表格范围扩展为 A1:AR201。已有记录的 AK:AN 留空，AO、AP 按第一批数据计算，因此历史数据口径保持不变。

## 5. 核心计算口径

### 5.1 累计股数

累计买入股数：

`第一批股数 + 第二批股数 + 第三批股数`

空批次按 0 处理。

### 5.2 实际加权买入价

实际加权买入价：

`(第一批价格×第一批股数 + 第二批价格×第二批股数 + 第三批价格×第三批股数) ÷ 累计买入股数`

累计股数为 0 时保持空白，避免除零错误。

### 5.3 当前有效止损

风险计算采用该交易在“持仓跟踪”中的最高“当前有效止损”。如尚无可用跟踪结果，则回退到“单次交易”的初始止损 N。

该口径确保止损上调后风险只会降低，不会因读取较早的跟踪记录而重新放大。

### 5.4 当前持仓风险

每批风险分别计算后求和：

`Σ MAX(该批买入价 - 当前有效止损, 0) × 该批股数`

当止损高于某批买入价时，该批风险按 0 计算，不计“负风险”。已卖出交易的当前持仓风险为 0。

### 5.5 风险上限

- 单笔允许亏损额沿用现有规则：账户总资金 C × 单笔风险比例 D。
- 账户整体风险沿用现有账户风险上限。
- 第二批或第三批填写后，只要该笔累计风险超过单笔允许亏损额，或所有未平仓交易累计风险超过账户上限，即判定为违规。
- 账户处于锁仓状态时，不允许录入第二批或第三批。

## 6. 强制规则与提示

“分仓规则检查”按优先级返回明确原因：

1. 交易编号为空：保持空白，不检查备用行；
2. 第一批价格或股数缺失；
3. 第二批价格与股数未成对；
4. 第三批价格与股数未成对；
5. 第二批未完整填写却填写第三批；
6. 任一批股数不是正整数或不是 100 的整数倍；
7. 锁仓期间发生加仓；
8. 该笔累计风险超过单笔上限；
9. 账户未平仓累计风险超过账户上限；
10. 通过。

AK:AN 使用自定义数据验证实施输入拦截。验证需允许删除可选批次，同时对成对填写、顺序、整手股数、锁仓和风险上限作严格检查。考虑到 Excel 粘贴可能绕过数据验证，AR 的公式检查是最终审计依据，并用条件格式突出违规。

第一批开仓继续受现有 G/H 开仓验证、锁仓、止损计划和交易预期必填规则约束；新增规则不得削弱这些限制。

## 7. 现有模块联动

所有涉及买入金额或持仓股数的公式统一改用三批汇总口径：

- “持仓跟踪”的实际卖出股数同步 AP 累计买入股数，而不是 H 第一批股数。
- 最终盈亏使用三批买入总金额、买入总费用、全部卖出金额和卖出费用计算。
- 持仓收益率的成本分母使用三批买入总金额及相关费用。
- 账户数据中的未平仓理论风险汇总 AQ 当前持仓风险。
- 平均交易金额、仓位和其他金额类统计使用三批买入总金额，或等价的 AO×AP。
- 锁仓统计继续依据每笔交易最终盈亏，不因分批买入而改变规则，但最终盈亏必须来自新的汇总成本。
- 动态止损继续按交易编号工作，止损触发后的卖出数量必须是 AP 累计股数。
- O“买入总费用”仍由用户填写，表示三批买入产生的费用总和；V5 不拆分各批手续费。

## 8. 兼容性与输出

- 以 `交易管理系统_V4_交易预期.xlsx` 为输入生成独立文件 `交易管理系统_V5_三批买入.xlsx`。
- 不覆盖原始文件及 V2、V3、V4 文件。
- 已有 100 笔交易不迁移、不改写价格和股数，只在新增公式列中将其视作单批交易。
- 保持 `.xlsx` 格式，不添加宏。

## 9. 验证方案

至少覆盖以下自动化测试：

- 只有第一批时，加权价格、累计股数与 V4 结果一致。
- 两批、三批的加权价格和累计股数计算正确。
- 可选批次半填、跳过第二批、非 100 整数倍均判定违规。
- 锁仓时加仓判定违规。
- 单笔风险刚好等于上限时通过，超过时违规。
- 账户累计风险刚好等于上限时通过，超过时违规。
- 止损上调后 AQ 风险正确下降，且不会为负数。
- 一次性卖出同步累计股数，并按三批总成本计算盈亏。
- 历史 100 笔交易的原始关键数据与 V4 一致。
- 工作簿可由 openpyxl 重新打开，ZIP 结构完整，并通过可用的渲染检查。

## 10. 已知限制

- 固定三批是对操作简单性的主动取舍；需要第四批时必须另开一笔交易记录或升级模型。
- 系统只支持一次性全部卖出，不能准确表达部分减仓。
- 工作表公式依赖交易编号稳定，不应对“单次交易”中的单行单元格进行局部错位排序。
- 无宏方案无法彻底阻止粘贴覆盖验证规则，因此必须同时依赖 AR 审计提示和条件格式。
